# TOKEN$HIT Traction Plan

**Goal:** Grow voters, holders, and X without sounding like a faucet farm.  
**Loop:** Vote / share → earn $TOKENSHIT → hold or swap → brag → bring friends.  
**Positioning:** Every token is shit until proven otherwise. Rate the bag. Earn $TOKENSHIT. Talk shit with skin in the game.

**Owners**
| Tag | Who |
|-----|-----|
| **You** | Metasal — approve content, KOLs, budget, Privy dashboard |
| **Agent** | Hermes — ship product, drafts, deploy, metrics pulls |
| **TF** | Typefully drafts only until you approve |

**Hard rules**
- Draft → Metasal approve → post. Never auto-tweet.
- No hashtags. No default emoji chrome. HIT/SHIT marks only where brand allows.
- No daily auto-meme crons.
- No price / 100x promises.
- Claims stay gated (X, ~100 followers, PFP).
